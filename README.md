# MLOps Demo

> **Project status:** Historical learning repository. The examples reflect the tools and course material available when the exercises were completed in 2023.

This repository records hands-on MLOps exercises for Azure Machine Learning. It was created from the [Microsoft Learning MLOps repository](https://github.com/MicrosoftLearning/mslearn-mlops) and is presented as learning work, not as an original production framework.

## Repository guide

- `documentation` contains the exercise instructions.
- `experimentation` contains exploratory notebooks and training work.
- `production` contains material for moving from experiments toward a repeatable workflow.
- `src` contains supporting Python code.
- `tests` contains automated checks used during the exercises.

## Running the exercises

Start with the hosted instructions in `index.md`. Check `requirements.txt` before running Python examples, as package versions and Azure services may have changed since this repository was last maintained.
